# t2-prDevWeb

Projet de cours — Thème 2 : recettes et listes de courses.

Application web prévue avec un front React et une API REST Node.js.

## Fonctionnalités prévues

- Gestion des recettes, ingrédients et listes de courses.
- Rôles User et Admin, avec contrôle des droits côté serveur.
- Accès limité aux données personnelles ou publiques.
- Interface adaptée au rôle et composant générique réutilisable.

## État du projet

Dépôt initialisé. L'application n'est pas encore développée.
Les instructions d'installation et de lancement seront ajoutées avec le code.

## Travail en groupe
